# CSU-Dissertation-Template-DIY
CSU-中南大学本科生毕业设计（论文）的一个DIY的Word模板，希望能帮到大家

# 前置
字体安装方法 1：
右键字体 --> 安装

字体安装方法 2：
1.找到 C:\WINDOWS\Fonts 文件夹
2.将需要安装的字体文件拖动至上述文件夹，等待自动安装字体

C:\Users\你的电脑用户名\AppData\Roaming\Microsoft\Templates
将“中南大学本科生毕业设计字体样式.dotm”复制到上述Templates文件夹下的目录，在word中导入

# 样式目录

字体样式目录（首数字代表样式分类，命名规则是：样式名_字体名及字体大小_附加的段落及其他设置）

封面页样式：
```
	1.封面中文标题_45磅黑体
	1.封面英文标题_一号黑体
	1.封面栏目_小二号黑体
	1.栏目内容_小二号楷体GB2312
	1.部门版权标识_二号黑体
	1.完成日期_小二号黑体
```

摘要及页眉样式：
```
	2.页眉_小五号黑体
	2.中文摘要字样_三号黑体_段前后一行
	2.中文题目_小二号黑体__段前后一行
	2.中文摘要内容_小四号宋体_首行两字符缩进
	2.英文题目_小二号加粗Times New Roman_段前后一行
	2.英文摘要字样_三号加粗Times New Roman_段前后一行
	2.英文摘要内容_小四号Times New Roman_首行缩进2字符
```

目录样式：
```
	3.目录字样_三号黑体_段前后一行
	3.目录一级标题_小四号宋体
	3.目录二级标题_小四号宋体
	3.目录三级标题_小四号宋体
```

正文、表格和图片样式：
```
	4.正文一级标题_三号黑体_段前后一行
	4.正文二级标题_小四号黑体_首行2缩进字符
	4.正文三级标题_小四号楷体GB2312_首行缩进2字符
	4.正文_中文小四号宋体_英文小四号Times New Roman_首行缩进2字符
	4.表格题目_五号黑体
	4.表格内容_中文五号宋体_英文五号Times New Roman
	4.公式
	4.图片
	4.图序和图题_五号黑体
```
        
结束与样式：
```
	5.结束语(或致谢)标题_三号黑体_段前后一行
	5.结束语(或致谢)正文内容_中文小四号宋体_英文小四号Times New Roman_首缩进2字符
```

参考文献样式：
```
	6.参考文献标题_三号黑体_段前后一行
	6.参考文献正文_五号楷体GB2312_1.5倍行距
```
